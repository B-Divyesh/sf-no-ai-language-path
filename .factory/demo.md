# Demo sandbox

Demo URL: <https://no-ai-language-path.sociobot.in/demo>

“Try it with sample data” opens a filled Spanish news routine in one click. The sample contains four blocks, 20 planned minutes, two completed sessions, and a three-session progression rule.

The banner remains visible on every demo route. “Reset demo” restores the original sample. “Start for real” deletes the demo database and opens the real routine.

Demo state uses IndexedDB database `demo:no-ai-language-path`. Real state uses `no-ai-language-path`. Tests seed real data, change and reset the sample, then prove the real data remains unchanged.
